# WHAT IS FETTA?

Product name:

**FETTA**

At this stage, Fetta is a **codebase understanding agent**.

The developer gives Fetta a local codebase/repository.

Fetta then deploys multiple specialist AI agents that rapidly understand different dimensions of the codebase.

Think of Fetta as an **AI engineering organization**, not a chatbot.

The agents behave conceptually like a solar system.

### The solar system = the engineering organization

The planets represent specialist agents.

For example:

* Database Agent → understands the database/schema
* Codebase/Architecture Agent → understands the overall structure and architecture
* Security Agent → understands security risks and implementation
* Backend Agent → understands backend systems
* Frontend Agent → understands frontend systems
* Testing Agent → understands testing and reliability

All of these specialist agents report into one central **Super Agent / Coordinator**.

The Super Agent is the central intelligence.

It has a very large context and persistent memory.

Its defining characteristic is:

**It does not forget what it has learned about the project.**

The specialists investigate.

The central intelligence synthesizes.

The result is a living understanding of the entire codebase.
